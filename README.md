# trustgame2026

This repository contains computational modeling and analysis code related to the preprint:

> Sedlinska, T. et al.  
> *Computational Markers of Altered Social Interaction and Cognition in Methamphetamine Use Disorder*  
> https://doi.org/10.31234/osf.io/9hyav_v1

The computational model implemented here is equivalent to the model described in:

> Hula, A., et al. (2021)

The repository combines:
- the original model implementation and task framework (`model/`)
- additional analysis pipelines
- extensions used for the present study
- figure generation and manuscript-related analyses

## Repository structure

- model/           original model and task implementation
- analysis/        new analysis scripts
